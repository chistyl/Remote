# TV Remote v1.1.2 測試報告

## 本輪修正

以使用者提供的 Remote ATV 5.0.5 APK 作為操作參考。從 APK Flutter AOT 字串資源確認原版包含 `Remote layout`、`Tap based control, as found on physical remote.`、`Swipe based touchpad, quick and convenient.`，以及「按住音量、頻道與導覽按鍵時模擬實體遙控器連續操作」的行為說明。

本輪據此完成：

1. 預設圓形方向鍵，中央 OK。
2. 按鍵模式／觸控板模式切換，模式保存於 SharedPreferences。
3. 頂部五個快捷按鍵：返回、首頁、選單、訊號源、電源。
4. 方向、音量及頻道按鍵支援按住連續操作；初始延遲 420 ms、重複間隔 115 ms。
5. 「長按連續操作」開關及偏好保存。
6. 清除原本重複的首頁、選單、電源、系統設定、訊號源按鍵列。
7. 版本升級為 `1.1.2`，`versionCode=14`。

## 已執行檢查

- `TouchpadMotion.kt` 與 `HoldRepeatTiming.kt` 使用 kotlinc 獨立編譯通過。
- 觸控滑動純邏輯回歸測試：短距離累積、斜向移動、長距離多格、單次事件步數上限、reset 清除累積值。
- 長按時間參數檢查：初始延遲大於重複間隔；初始延遲 300–700 ms；重複間隔 80–180 ms。
- 首頁及中央 OK 長按事件的 UI 呼叫路徑已檢查，分別呼叫 `sendLongKey(HOME)`、`sendLongKey(DPAD_CENTER)`。
- UI 語系鍵值檢查：本輪新增 `dpad_mode`、`touchpad_mode`、`hold_repeat` 均已提供繁中／英文／越南文。
- Android Manifest／資源 XML 解析通過。
- 檢查舊版重複控制列已移除。
- ZIP 完整性檢查通過。

## 尚未執行

- Android Gradle 全專案編譯及 `testDebugUnitTest`。
- APK 產生、安裝及 Android 9 實機測試。
- 與原版 5.0.5 的畫面像素級比對（目前沒有原版完整 UI 原始碼或逐頁操作錄影）。
