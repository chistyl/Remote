# TV Remote v1.1.6 除錯報告

## 本次修正
- PairingClient 加入 pairingGeneration，舊工作不能覆寫新配對狀態。
- CancellationException 不再被當成一般配對失敗。
- cancel() 遞增世代、取消工作、關閉目前 socket、清除錯誤與狀態。
- finally 僅關閉該次配對工作建立的 socket，避免舊工作誤關新連線。
- 各配對階段完成後檢查世代；世代已變更時以 CancellationException 結束，不當成一般錯誤。

## 本次驗證
- PairingClient、PairingProtocol、ProtoCodec 使用 Kotlin 1.9.0 與輕量 Android/TLS/coroutine 替身完成編譯，通過。此為語法與型別檢查，不代表 Android 完整建置。
- AndroidManifest.xml、strings.xml、styles.xml XML 解析通過。
- versionName/versionCode 與配對競態修正項目靜態檢查通過。
- ZIP 完整性檢查通過。
