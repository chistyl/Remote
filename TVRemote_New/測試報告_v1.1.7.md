# TV Remote v1.1.7 除錯報告

## 本次修正
- 發現 v1.1.6 仍有一個取消競態窗口：舊工作完成 TLS socket 建立後，若取消恰好發生在世代檢查與共享 socket 指派之間，舊工作可能在取消後才將 socket 指派回共享欄位。
- 新增 pairingLock，將配對世代遞增、socket 指派、狀態更新、錯誤寫入、取消及 finally 清理序列化。
- pairingGeneration/socket 使用 volatile，讓跨執行緒檢查可見。
- 舊配對工作在 socket 指派前再次於鎖內核對世代；已取消即不接受該 socket。
- 配對狀態更新只允許目前世代執行，避免舊工作覆寫新工作狀態。
- 版本更新為 1.1.7（versionCode 19）。
