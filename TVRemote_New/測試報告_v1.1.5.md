# TV Remote v1.1.5 除錯與修正報告

## 本輪找到並修正
1. **切換不同電視時仍連到舊電視**
   - 舊版 `RemoteClient.connect()` 只要舊連線工作仍 active 就直接 return。
   - 因此從已連線狀態切換到另一台已儲存電視，可能不會真正切換。
   - 現在會先關閉舊連線，再連到新 IP。
   - 加入 connection generation token，避免舊連線 coroutine 的 `finally` 清除新連線的狀態。

2. **mDNS 服務已消失仍留在待解析佇列**
   - 收到 `onServiceLost` 時，同步移除尚未解析的同名服務，避免過期裝置被加入列表。

3. **保留 v1.1.4 修正**
   - Android 9 NSD 序列化解析。
   - 語音錄音頁面離開時取消最新錄音工作。
   - 原有按鍵、觸控板、長按連續操作與多語系。

## 驗證
- 純 Kotlin 協定／觸控板／長按核心編譯與回歸 harness：通過。
- `RemoteClient`、`PairingClient`、`ProtoCodec`、`PairingProtocol` 使用 Android/TLS API stub 進行 Kotlin 編譯：通過（僅驗證 Kotlin 語法與 coroutine 型別，不等同 Android Gradle build）。
- TCP frame 每個分段位置、Unicode IME、PIN digest、觸控板累積與長按時序：通過。
- Android Manifest、strings、styles XML：通過。
- 完整 Android Gradle 編譯、APK 安裝與 Android 9 實機測試：尚未執行（此執行環境沒有 Android SDK／Gradle）。
