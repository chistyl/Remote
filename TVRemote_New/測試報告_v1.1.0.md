# TV Remote v1.1.0 測試報告

## 已執行並通過

- `ProtoCodec.kt`：獨立 Kotlin 編譯；驗證 protobuf varint、TCP frame、UTF-8、IME、音量欄位、靜音欄位、電源狀態、語音 session 與語音 payload 長度。
- `RemoteClient.kt`：搭配 Android Log 與 TLS 替身類別、Kotlin Coroutines 編譯通過。
- `PairingClient.kt`：搭配憑證與 TLS 替身類別、Kotlin Coroutines 編譯通過。
- `VoiceRecorder.kt`：搭配 Android AudioRecord API 替身類別、Kotlin Coroutines 編譯通過。
- `TouchpadMotion.kt`：獨立 Kotlin 編譯；短距離累積、長距離連續、斜向、單次上限及剩餘距離測試通過。
- Android Manifest 與資源 XML：XML parser 格式檢查通過。
- 靜態清理：主要程式碼已無 ADB 診斷功能、電視 APP 自訂快捷清單或 APP_LINK 啟動程式。

## 尚未執行

- Android Gradle 全專案編譯、`testDebugUnitTest`、APK 產生。
- 實際手機安裝、Android 9 電視配對、方向鍵、觸控板、音量回報及麥克風語音實機測試。

原因：目前執行環境沒有 Android SDK、Gradle、Android Build Tools 及實體 ADB 裝置。替身類別編譯只能驗證對應 Kotlin 語法，不能代替 Android SDK 的完整建置或電視實機驗證。
