# TV Remote v1.1.3 測試報告

## 本輪修正
- 對遙控控制元件使用的 `combinedClickable` 加上檔案層級 ExperimentalFoundationApi opt-in，避免 Compose API 實驗性標註造成編譯阻擋。
- Android 版本升級為 versionCode 15、versionName 1.1.3。
- 保留 v1.1.2 的方向鍵／觸控板切換、長按連續操作、Home／OK 長按、三語系與原本遙控協定。

## 已執行檢查
- Kotlin 純邏輯檔案獨立編譯：通過（TouchpadMotion、HoldRepeatTiming）。
- 純邏輯測試 harness：通過（移動累積、斜向手勢、步進上限、重設、長按時間界限）。
- AndroidManifest 與資源 XML 解析：通過。
- 專案設定、版本資訊、重複遙控列靜態檢查：通過。
- 原始碼 ZIP 完整性：待封裝後檢查。

## 尚未完成／不可宣稱通過
- 本執行環境沒有 Android SDK、Gradle 與 adb。
- 尚未執行完整 `:app:testDebugUnitTest`、`:app:assembleDebug`。
- 尚未產生可安裝 APK，也未在 Android 9 實機與電視上配對測試。

**結論：** v1.1.3 已完成可執行的靜態修正與有限測試；完整 Android 編譯與實機驗證仍待具備 Android SDK 的 CI 環境執行。不可將本版本視為已通過安裝測試。
